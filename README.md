# hxwl-11 干眼热脉动疗程台

按患者与眼别管理热脉动疗程：两次泪膜破裂时间、角膜染色评分与仪器时段一体化记录，
指标异常自动转待复核并释放时段，不良事件一键冻结疗程。

## 技术栈

React 19 + Vite + TypeScript + CSS，数据保存在浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 分层结构

| 目录 | 职责 |
| --- | --- |
| `src/domain` | 领域模型与**判定**规则（纯函数）：破裂时间均值 < 5s 或染色 ≥ 3 级 → 待复核；时段占用唯一性；冻结转换 |
| `src/data` | **数据**层：localStorage 持久化、排机/检查/复核/完成/冻结等状态流转动作 |
| `src/archive` | **留档**层：定义需要记录的事件与审计文案 |
| `src/ui` | **界面**层：指标卡、患者侧栏、疗程面板、仪器时段表、留档列表 |

## 业务规则

- 按患者 + 眼别建立疗程（每疗程 3 次），每次保存两次破裂时间、染色评分与仪器时段。
- 同一仪器同一时段只能安排一人；排机与医生复核重排均做冲突拦截。
- 两次破裂时间取均值，均值不足 5 秒或角膜染色达到 3 级：
  自动转「待复核」并立即释放已占时段，时段在排班表中恢复可约。
- 护理后复查由医生确认继续并重新排机；只有「待上机」状态可完成治疗。
- 出现角膜上皮脱落或灼伤：冻结计划、记录原因，后续预约全部取消并停止排机。
- 建疗程、排机、检查录入、判定、释放时段、复核、完成、冻结、取消全部留档。

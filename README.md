# 干眼热脉动疗程台

按患者与眼别管理干眼热脉动疗程的评估、判定、仪器排机与留档。

## 规则

- 按「患者 + 眼别」存档：两次泪膜破裂时间（BUT）、角膜染色分级、仪器日期/仪器/时段。
- 同一仪器同一时段只安排一人；状态不对（待复核、待医生确认、冻结）不能排机。
- 任一眼 BUT 不足 5 秒或染色达到 3 级：进入**待复核**，自动释放已占时段；护理后复查提交后由**医生确认继续**，确认前不排机。
- 出现**角膜上皮脱落或灼伤**（医生登记）：立即冻结计划、记录原因、释放时段并停止一切后续预约。
- 所有操作与自动判定只追加留档。

## 分层

- `src/types.ts`：领域模型
- `src/domain/`：仪器/时段目录、判定规则（纯函数）、留档工具
- `src/data/`：reducer 数据层、localStorage 持久化、演示数据
- `src/components/`：界面（录入、流转、时段表、档案、留档）
